# rust-libcint
Provide wrappers for libcint (C)

Online documentation is given on https://igor-1982.github.io/rest_libcint/rest_libcint/

## For developer of rest_libcint

To run cargo test successfully, you are adviced to
- set environment variable `CINT_DEV=1`
- set environment variable `CINT_DIR` to the directory where the compiled libcint library is located.
